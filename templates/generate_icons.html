How to use these files

  1. Click each Download button above to save both PNGs.
  2. Move them to your project's static/icons/ folder, overwriting any existing files.
  3. Run python manage.py collectstatic --noinput to publish them.
  4. Confirm your manifest.json points to /static/icons/icon-192.png and /static/icons/icon-512.png.
